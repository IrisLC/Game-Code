# Spiral
Samples of code written for the currently in development game _Spiral_, created as part of my senior capstone. 

All code here was almost if not entirely written by myself, with some lines being authored by the other programmer on the project. Files which were mainly written by the other programmer, or which were a more collaborative process between the two of us have not been included for sake of clarity as to code authorship.

These code samples are from a point where Spiral has been in development for ~5 months, with development largely being paused for ~3 months due to summer responsibilities. This means that most of the functionality of the code was written over the span of only about 2 months, with refactoring work being done on and off over the course of the summer. 
As development progresses, these samples will be updated accordingly.

For more information on _Spiral_ click [here](https://irislc.github.io/Projects/Spiral.html)
